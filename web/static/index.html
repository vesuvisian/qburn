qburn

Run Qwen3-VL with Burn — images and video, same Rust model on the command line and in the browser.

Burn demo transformers.js demo

Drop in a photo or a short clip, ask for a description, and the model streams a caption back. Demos take up to four images or one video (four sampled frames); the CLI can sample more with --fps / --num-frames.

Two browser demos, same job. The Burn demo is the unusual one: vision and language are ported to Burn modules in Rust — no ONNX export in the middle. What you run with cargo run -p qburn on Metal or CUDA is what the wasm build runs on WebGPU.

The transformers.js demo is the traditional path people already use: export to ONNX, let ONNX Runtime drive WebGPU. It’s currently much faster due to better backend optimizations, so it’s here as a fair baseline, not a rival product. You’ll need WebGPU for both.

More details can be found in the pipeline walkthrough, the Burn vs transformers.js notes, and on GitHub.
