qburn

Run Qwen3-VL with Burn — the same Rust model on the command line and in the browser.

Burn demo transformers.js demo

Drop in a photo, ask for a description, and the model streams a caption back. Vision and language are written as Burn modules — no ONNX in the middle. What you run with cargo run -p qburn on Metal or CUDA is what the wasm build runs on WebGPU.

You’ll need a browser with WebGPU. The Burn demo pulls about 1.8 GiB of weights (q4-mix) and is honestly slow — a short caption can take a minute. That’s fine for poking at the stack; for real speed, use the CLI. The transformers.js page is here so you can try the usual ONNX path side by side.

There’s a walkthrough of the pipeline, a Burn vs transformers.js write-up, and the full project on GitHub.
